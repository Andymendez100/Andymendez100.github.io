# Minion Privacy Policy

_Last updated: September 10, 2026_

Minion is a personal AI assistant used only by its owner, Andy Mendez. It is not offered to the public. This policy also covers "Hermes Calendar Hub," the Google sign-in app Minion uses.

## What data it accesses

With the owner's permission through Google OAuth, Minion reads and updates Google Calendar events, reads the list of calendars, and manages calendars on the owner's Google account. It uses this only to keep the owner's calendars in sync.

## How data is used and shared

- Data is used only for the owner's own scheduling.
- Data is not sold, shared with third parties, or used for advertising.
- OAuth tokens are stored only on the owner's private computer.

Minion's use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access

Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).
